# The Internet in One Word

Entry for make.fun competition
`u-ronigrv-the-internet-in-one-word-e388f33b`.

The brief asks for one word describing the whole internet. Our word is
**captcha** — the one place where humans spend their days proving to
machines that they are human.

`main.py` writes exactly `captcha` (7 bytes, no trailing newline)
to `/output/entry.txt`, deterministically, with no network access.

Run it with:

```sh
python3 main.py
```
